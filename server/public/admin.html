개발자: 모든 권한과 관리 창 · 임원진(팀장·부팀장·파트장): 팀원 권한 + 차량 설정·주행 전 점검 항목·일정 관리 · 부팀장: 임원진 + 총무(사비 정산 지급 처리) · 팀원: 부품·테스트 기록·사비 내역서 제출. 개발자도 직책을 겸할 수 있어요. 바꾸면 그 사람의 화면이 바로 새 권한으로 다시 연결돼요.

여기서 직접 고치면 페이지의 권한 규칙과 양식 검사를 거치지 않아요. 고치기 전에 백업을 만들어 두세요. 모든 수정은 감사 로그에 남아요.

백업

전체 백업 내려받기 (첨부 파일 포함)

아래 목록의 백업(JSON)에는 모든 데이터 문서, 계정(비밀번호는 암호화된 상태), 설정, 첨부 파일 목록이 들어가요. 첨부 파일까지 한 파일로 받으려면 전체 백업 내려받기(.tar.gz)를 쓰세요. 결제 정보와 계정이 들어 있으니 안전한 곳에만 보관하세요.

파일종류크기만든 시각관리

외부 복사 (USB 드라이브 · 네트워크 폴더)

매일 자동 백업이 끝나면 백업 파일과 첨부 파일을 이 폴더로 복사해요. 복사본에서는 지우지 않으니 서버 데이터가 지워져도 남아 있어요. 라즈베리파이에 꽂은 USB 드라이브 경로를 적으세요.

전체 백업으로 복원

전체 백업 내려받기로 받은 .tar.gz 파일에서 데이터 문서와 첨부 파일을 되살려요. 계정과 설정은 바뀌지 않아요 (계정까지 되돌리려면 서버에서 npm run admin -- restore 파일.tar.gz --force). 복원 직전 상태는 자동으로 백업돼요.

claude.ai 피트보드에서 옮기기

claude.ai에서 쓰던 피트보드 데이터를 이 서버로 옮겨요. ① claude.ai에서 Claude에게 "피트보드 Artifact 데이터를 내보내 줘"라고 요청해 JSON을 받아요. ② 팀원들이 이 서버에 먼저 가입해요. ③ 파일을 고르면 사비 정산·총무 기록·점검 체크에 남은 claude.ai 계정이 나와요. 각 사람을 이 서버 계정과 짝지은 뒤 가져오면 그 사람의 기록이 새 계정으로 옮겨져요.

데이터 가져오기

백업 파일이나 claude.ai 피트보드에서 내보낸 JSON({ docs: [{ path, data }] })을 가져와요. 가져오기 직전 상태는 자동으로 백업돼요. 계정은 바뀌지 않아요.
