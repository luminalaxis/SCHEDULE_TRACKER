# FSK 피트보드

FSK(Formula Student Korea) 차량 제작동아리용 팀 현황판입니다. 부품 제작 진행, 주행 테스트, 대회 일정, 사비 정산을 한 페이지에서 30명 안팎의 팀원이 함께 씁니다.

claude.ai Artifact로 배포되며, 데이터는 Artifact의 공유 데이터베이스(`db`)와 파일 저장소(`assets`)에 저장됩니다. 이 저장소에는 페이지 소스와 배포 설정만 있고, 팀 데이터는 들어 있지 않습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 부품 현황 | 제작 진행률, 차량 질량(목표 대비), 부품 비용(예산 대비), 마감 지난 부품, 부서별 현황, 부품 목록(단계 변경·검색·필터), BOM CSV 내보내기, EV 기본 부품 목록 |
| 테스트 세션 | 주행 세션별 출주 전 점검(부서별 체크, 체크한 사람·시각 기록), 부서별 기록(판정·측정값·셋업 변경·관찰·분석·다음 액션), 관련 부품 연결, 첨부 파일, 부서 간 의견 |
| 추이 분석 | 부서별 측정값의 세션 간 추이 그래프(종목별 필터), 세션 × 부서 판정표 |
| 이슈 | 주의·문제 판정 기록 모음, 해결 여부 체크 |
| 일정 | 서류 마감·차량 검사·대회 등 마일스톤, 가장 가까운 일정은 머리글 D-day 아래 표시 |
| 사비 정산 | 사비 내역서(xlsx) 제출과 양식 자동 검사, 총무의 지급 상태 관리, 삭제·복구 |
| 변경 이력 | 누가 언제 무엇을 바꿨는지 자동 기록 (90일 보관) |

부서는 배터리 · 회로 · 프레임·현가 · 에어로 · 파워트레인 다섯 개입니다.

## 사비 정산

### 양식 자동 검사

동아리 양식 `개인사비사용내역서_이름_날짜.xlsx`를 브라우저에서 바로 읽어 검사합니다(JSZip, 엑셀·한셀 저장 파일 모두 지원).

- `내역서`·`영수증` 시트, 2행 머리글(B2:K2)
- 각 항목: 필수 칸, 팀명·구분이 양식의 숨김 목록 값인지, 날짜, 단가·수량 숫자, 합계 = 단가 × 수량
- 총 합계(K13), 계좌번호(H13) 자릿수·은행명
- 영수증 사진 유무와 구매 건수 대비 장수
- 배송비 구분, 구매처 링크·주소, 파일명 규칙, 같은 파일 중복 제출

결과는 `양식 통과` / `확인 필요` / `양식 불일치` 세 단계이며, 팀원은 양식 불일치 파일을 제출할 수 없습니다.

### 지급 상태

`검토 대기` → `보완 요청` / `승인 · 지급 대기` → `지급 완료` / `반려`

### 권한

| | 팀원 | 총무 | 개발자(소유자) |
|---|---|---|---|
| 내역서 제출 | ✅ (설정으로 끌 수 있음) | ✅ (대리 등록 포함) | ✅ |
| 지급 상태 변경, 수정본 교체 | ❌ | ✅ | ✅ |
| 전체 계좌번호 보기, 원본 내려받기 | 본인 것만 내려받기 | ✅ | ✅ |
| 삭제(목록에서 숨김)·복구 | ❌ | ✅ | ✅ |
| 완전 삭제(데이터·파일) | ❌ | ❌ | ✅ |
| 총무 지정 | ❌ | ❌ | ✅ |

권한은 서버의 데이터베이스 규칙(`artifact.config.json`)으로 보호됩니다.

- 각 사람은 자기 영역(`expenses/<id>`, `reviews/<id>`, `people/<id>`)에만 쓸 수 있습니다.
- `config/roles`(총무 목록)는 소유자만 쓸 수 있습니다.
- 지급 상태는 `reviews/<id>`에 기록되며, 페이지는 총무 목록에 있는 사람(과 소유자)의 기록만 인정합니다.

알려진 한계:

- 제출자는 자기 영역에 있는 제출 내용을 기술적으로 바꿀 수 있습니다. 총무 검토 뒤 내용이 바뀌면 "검토 후 변경됨"으로 표시됩니다.
- 화면 이름은 각자 입력한 이름입니다. 권한은 이름이 아니라 claude.ai 계정 기준입니다.
- 원본 xlsx는 지원 형식 제한 때문에 base64 텍스트로 저장됩니다. 페이지를 열 수 있는 사람에게서 완전히 숨겨지지는 않습니다.

## 데이터 구조 (`db`)

| 경로 | 내용 |
|---|---|
| `parts/*` | 부품 (부서, 단계, 수량, 질량 g, 비용 원, 담당, 마감, 첨부) |
| `config/car` | 차량 이름, 대회 날짜, 목표 질량, 예산 |
| `config/checklist` | 출주 전 점검 항목 |
| `config/roles` | 소유자 id, 총무 id 목록, 팀원 제출 허용 여부 (소유자만 쓰기) |
| `sessions/*` | 테스트 세션 (생성 시점의 점검 항목 사본 포함) |
| `logs/*` | 부서별 테스트 기록 (측정값, 관련 부품 id, 첨부) |
| `comments/*` | 기록에 단 의견 |
| `checks/<세션>--<항목>` | 점검 체크 |
| `milestones/*` | 일정 |
| `history/*` | 변경 이력 (90일 지나면 자동 정리) |
| `people/<id>` | 이름·부서 (본인만 쓰기) |
| `expenses/<id>` | 그 사람의 사비 내역서 제출 묶음 (본인만 쓰기) |
| `reviews/<id>` | 그 사람이 남긴 검토·지급 기록 (본인만 쓰기, 총무·소유자 것만 인정) |

## 배포

`index.html`은 Artifact 페이지 본문입니다(`<!doctype>`, `<head>`, `<body>`는 배포 시 자동으로 감싸짐). `artifact.config.json`의 `capabilities`와 함께 claude.ai Artifact로 게시해야 데이터 저장, 파일 첨부, 권한이 동작합니다. 브라우저에서 파일을 직접 열면 화면은 보이지만 "팀 저장소에 연결할 수 없어요"로 표시됩니다.

팀원이 기록을 남기려면 Artifact의 Share 메뉴에서 편집자로 초대해야 합니다.
