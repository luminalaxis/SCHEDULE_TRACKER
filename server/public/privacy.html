3. 누가 볼 수 있나요

  • 로그인한 팀원 모두: 이름, 부서, 직책, 팀 작업 기록, 사비 내역서 목록과 금액
  • 제출자 본인, 총무(부팀장), 개발자만: 사비 내역서 원본 파일, 영수증 사진, 전체 계좌번호
  • 개발자만: 감사 로그(IP 주소), 관리 창의 모든 데이터와 백업

4. 외부로 나가는 정보

  • 개인정보를 팔거나 다른 곳에 넘기지 않아요. 데이터는 동아리가 운영하는 서버와, 개발자가 정한 외부 복사 장치(USB 등)에 저장해요.
  • 밖에서 접속할 수 있게 Cloudflare Tunnel을 쓰면, 접속 내용이 암호화된 채로 Cloudflare를 거쳐 서버에 와요.
  • 팀 채널 알림(지금 {{webhook}}): 켜져 있으면 Discord 또는 Slack 팀 채널로 일정 알림, 마감 지난 부품 요약, 테스트 주의·문제 판정을 보내요. 부품 담당자 이름이 들어갈 수 있어요. 돈과 관련된 알림은 보내지 않아요.
  • 글꼴을 포함한 화면 파일은 모두 이 서버에서 받아요. 광고, 방문 분석, 추적 도구는 쓰지 않아요.

5. 기기에 저장하는 것 (쿠키 등)

  • 로그인 쿠키(fsk_session): 로그인을 유지하는 데 꼭 필요해요. {{sessionDays}}일 동안 유지되고, 로그아웃하면 지워요.
  • 기기 저장소: 인터넷이 끊겨도 열 수 있게 마지막으로 본 데이터와 아직 올리지 못한 변경을 저장해요. 로그아웃하면 지워요. 일반/TV 화면 선택, 닫은 안내 같은 화면 설정은 남아요.
  • 광고·분석·추적 쿠키는 없어요. 그래서 쿠키 동의 창을 띄우지 않아요.

6. 내 정보 확인·수정·삭제

내 정보를 확인하거나, 고치거나, 지우거나, 처리를 멈춰 달라고 요청할 수 있어요. 이름과 부서는 개발자가 고쳐요.

삭제를 요청하면 개발자가 계정을 지우면서 개인정보 정리를 해요.

  • 사비 내역서 원본 파일, 영수증 사진, 계좌 정보 삭제 (금액·항목은 이름 없이 동아리 회계 기록으로 남아요)
  • 팀 작업 기록에 남은 내 이름을 "탈퇴한 팀원"으로 변경
  • 감사 로그의 내 IP 주소 삭제, 로그인 세션·알림 삭제

7. 안전하게 지키는 방법

  • 비밀번호는 되돌릴 수 없는 해시로만 저장해요.
  • 계좌번호가 든 원본 파일과 영수증은 제출자·총무·개발자만 열 수 있게 서버가 막아요.
  • 데이터 폴더와 파일은 서버 계정만 읽을 수 있고, HTTPS로 접속하면 연결이 암호화돼요.
  • 로그인, 권한 변경, 데이터 직접 수정은 감사 로그에 남아요.
