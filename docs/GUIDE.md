## 1. 처음 시작하기

1. 개발자에게 받은 피트보드 주소로 들어가요.
2. **가입 신청** 탭에서 이름, 부서, 아이디(영문 소문자·숫자 3~32자), 비밀번호(8자 이상)를 적어요.
   - **부서는 가입 뒤에 개발자만 바꿀 수 있어요.** 정확히 고르세요. 부서는 배터리 · 회로 · 프레임·현가 · 에어로 · 파워트레인 중 하나예요.
   - 초대 코드 칸이 보이면 개발자에게 받은 코드를 넣어요. 코드가 맞으면 바로 쓸 수 있어요.
3. 승인제라면 개발자가 승인할 때까지 기다린 뒤 **로그인**해요.
4. 처음 들어가면 **오늘** 탭이 열려요. 오른쪽 위 이름과 부서가 맞는지 확인하세요.

> 비밀번호를 잊었으면 개발자에게 초기화를 요청하세요. 임시 비밀번호로 로그인하면 새 비밀번호를 정하는 화면이 나와요.

## 2. 화면 한눈에 보기

맨 위 머리글에 차량 이름과 **대회까지 D-day**, 그 아래 가장 가까운 일정이 보여요. 오른쪽 위에는 **알림**, **일반 / TV** 전환, 로그아웃이 있어요.

| 탭 | 언제 쓰나요 |
|---|---|
| 오늘 | 매일 처음 보는 곳. 급한 것과 내 부서 할 일 |
| 부품 현황 | 부품 등록, 제작 단계 바꾸기, 질량·비용 확인 |
| 테스트 세션 | 주행 테스트 날 출주 전 점검과 부서별 기록 |
| 추이 분석 | 세션마다 측정값이 어떻게 변했는지 그래프로 |
| 이슈 | 테스트에서 주의·문제로 나온 것들과 해결 여부 |
| 일정 | 서류 마감, 차량 검사, 대회 날짜 |
| 사비 정산 | 사비로 산 물품의 내역서 제출과 지급 상태 |
| 변경 이력 | 누가 언제 무엇을 바꿨는지 (90일 보관) |

## 3. 매일 쓰는 법: 오늘 탭

- 위쪽 카드: **마감 지난 부품 · 3일 안 마감 · 미해결 이슈 · 다음 일정 · 출주 전 점검 진행**. 카드를 누르면 해당 목록으로 바로 가요.
- 아래쪽 목록: **내 부서의 남은 부품**을 마감이 가까운 순서로 보여 줘요. 내가 담당한 부품에는 "내 담당" 표시가 붙어요.
- 내 부서는 가입할 때 정한 부서예요. 배지로만 보이고 직접 바꿀 수 없어요.

하루 루틴 추천: 오늘 탭 확인 → 진행한 부품의 단계 바꾸기 → 알림 확인.

## 4. 부품 관리

### 부품 추가

**부품 현황 → + 부품 추가**에서 적어요. 부품명만 필수예요.

| 칸 | 설명 |
|---|---|
| 부품 번호, 부서 | 부서는 진행률·알림을 나누는 기준이에요 |
| 구분 | 제작 / 구매 |
| 제작 단계 | 설계 → 발주 → 가공 → 검수 → 조립 → 완료 |
| 수량, 개당 질량(g), 개당 비용(원) | 차량 질량과 예산 합계에 들어가요 |
| 담당자 | 계정 목록에서 골라요. 마감 알림이 이 사람에게 가요 |
| 공급처 / 가공처, 마감일, 메모 | |
| 첨부 파일 | 도면, 견적서, 사진 (PNG·JPG·PDF·CSV·TXT·MP4 등, 파일당 20MB) |

부품이 하나도 없을 때는 **기본 부품 목록 넣기 (EV)** 로 프레임, 업라이트, 어큐뮬레이터, TSAL 같은 흔한 부품 이름을 한 번에 넣을 수 있어요. 질량·비용·담당은 비어 있으니 팀에 맞게 고치거나 지우면 돼요.

### 진행 상황 바꾸기

- 부품 목록에서 단계 칸을 바로 바꾸면 돼요. 창을 열 필요 없어요.
- 검색, 부서·단계 필터(미완료만, 마감 지남, 테스트 이슈 있음), 정렬(부서순·마감 임박순·최근 수정순·무거운 순)을 쓸 수 있어요.
- 테스트에서 주의·문제 판정과 연결된 부품에는 ⚠ 표시가 붙어요.
- **BOM 내보내기 (CSV)** 로 비용 보고서용 목록을 받을 수 있어요.

### 🔒 잠긴 부품

설계가 확정된 부품은 그 부서 파트장, 팀장·부팀장, 개발자가 잠글 수 있어요. 잠긴 부품은 이 사람들만 고치거나 지울 수 있어요. 바꿔야 하면 파트장에게 말하세요.

## 5. 테스트 세션 (주행 테스트 날)

### 세션 만들기

**테스트 세션 → + 새 세션**: 날짜(필수), 종목(셰이크다운·가속·스키드패드·오토크로스·엔듀런스·브레이크 테스트·자유 주행), 장소, 날씨, 기온, 노면 온도, 랩 수, 테스트 목적을 적어요. 만들 때의 출주 전 점검 항목이 세션에 복사돼요.

### 출주 전 점검

- 세션 화면 위쪽에 부서별 점검 항목이 있어요. 확인한 항목을 체크하면 **누가 언제 체크했는지** 남아요.
- 모두 체크되면 **✓ 출주 준비 완료**가 떠요.
- 트랙에서 신호가 약해도 체크할 수 있어요 ([10장](#10-휴대폰--트랙에서-쓰기)).

### 부서 기록 남기기

**+ 부서 기록**(또는 부서 칸의 **+ 기록 남기기**)을 눌러요.

| 칸 | 설명 |
|---|---|
| 판정 | ✓ 정상 / ! 주의 / ✕ 문제 |
| 측정값 | 부서마다 정해진 항목. 비워 두면 기록하지 않아요 (아래 표) |
| 셋업 변경 · 관찰 · 분석·결론 · 다음 액션 | 자유롭게 |
| 관련 부품 | 주의·문제 판정이면 그 부품에 ⚠ 표시가 붙어요 |
| 첨부 파일 | 데이터로거 CSV, 사진, 영상 (파일당 20MB) |

| 부서 | 측정값 |
|---|---|
| 배터리 | 시작·종료 SOC, 최고 셀 온도, 최저 셀 전압, 최대 방전 전류, 소모 에너지 |
| 회로 | LV 최저 전압, 셧다운 회로 트립, CAN 오류, BMS·IMD 폴트, 하네스 최고 온도 |
| 프레임·현가 | 공기압 FL·FR·RL·RR, 캠버 F·R, 차고 F·R, 타이어 최고 온도 |
| 에어로 | 프론트·리어 윙 받음각, 다운포스 추정, 코스트다운 감속, 최고 속도 |
| 파워트레인 | 모터·인버터·냉각수 최고 온도, 최고 출력, 최고 속도, 최종 감속비 |

다른 부서 기록에는 **의견**을 달 수 있어요. 의견이 달리면 기록을 쓴 사람에게 알림이 가요.

## 6. 추이 분석 · 이슈

- **추이 분석**: 부서별 측정값이 세션마다 어떻게 변했는지 그래프로 보여 줘요. 종목으로 거를 수 있고, 아래 **세션 × 부서 판정** 표의 행을 누르면 그 세션으로 가요. **지표 값 표로 보기**로 숫자를 볼 수 있어요.
- **이슈**: 주의·문제 판정 기록이 모여요. 다음 액션을 끝냈으면 **해결됨**을 체크하세요. 탭 옆 숫자는 미해결 이슈 수예요.

## 7. 일정

설계 보고서·비용 보고서·ESF 마감, 차량 검사, 대회 날짜 같은 일정이 있어요. 가장 가까운 일정이 머리글 D-day 아래에 보여요. 담당 부서로 거를 수 있어요.

일정 추가·수정은 임원진이 해요 ([12장](#12-임원진--총무가-하는-일)).

## 8. 사비 정산

### 제출하기

1. 동아리 양식에 내역을 적고 영수증 사진을 붙여 `개인사비사용내역서_이름_날짜.xlsx`로 저장해요 (엑셀·한셀 모두 돼요).
2. **사비 정산 → + 사비 내역서 제출**에서 파일을 골라요. 바로 양식 검사를 해요. 파일은 14MB까지예요. 너무 크면 영수증 사진 크기를 줄여서 다시 저장하세요.
3. 신청자 이름(돈을 받을 사람)을 확인하고 **제출**해요.

### 자동 검사 결과

| 결과 | 뜻 |
|---|---|
| ✓ 양식 통과 | 그대로 제출하면 돼요 |
| ! 확인 필요 | 제출은 되지만 총무가 볼 부분이 있어요 (예: 영수증 장수가 적음) |
| ✕ 양식 불일치 | 제출할 수 없어요. 표시된 문제를 고쳐서 다시 올리세요 |

검사하는 것: `내역서`·`영수증` 시트, 필수 칸, 팀명·구분 값, 날짜, 단가 × 수량 = 합계, 총 합계, 계좌번호·은행명, 영수증 사진 유무와 장수, 배송비 구분, 구매처 링크·주소, 파일명, 같은 파일 중복 제출.

### 제출한 뒤

- 진행 순서: `검토 대기` → `보완 요청` 또는 `승인 · 지급 대기` → `지급 완료` (또는 `반려`)
- 상태가 바뀌면 알림이 와요. 총무 메모와 지급액도 함께 보여요.
- **제출한 내역서는 직접 고치거나 지울 수 없어요.** 바꿀 게 있으면 총무에게 수정본 교체를 부탁하거나 새로 제출하세요.
- 원본 파일과 영수증은 나, 총무, 개발자만 볼 수 있어요. 다른 팀원에게는 목록과 금액만 보여요.
- **내 제출만** 체크로 내 것만 볼 수 있어요.

## 9. 알림

오른쪽 위 **알림**에 모이고, 페이지를 열어 두면 바로 떠요. 알림을 누르면 해당 내역서·세션·부품으로 가요.

| 무엇 | 누구에게 |
|---|---|
| 사비 정산 보완 요청 · 승인 · 지급 완료 · 반려 | 제출한 사람 |
| 새 사비 내역서 | 총무 |
| 내 부서 기록에 달린 의견 | 기록을 쓴 사람, 앞서 의견을 단 사람 |
| 부품 마감 D-3 이내 · 오늘 · 지남 | 부품 담당 (없으면 그 부서 파트장) |
| 일정 D-7 · D-1 · 당일 | 모두 (담당 부서가 있으면 그 부서) |

마감·일정 알림은 아침 8시 이후에 와요. 팀 채널(Discord·Slack)이 연결돼 있으면 일정, 마감 지난 부품 요약, 테스트 주의·문제 판정도 채널로 가요. 돈 관련 알림은 채널로 가지 않아요.

## 10. 휴대폰 · 트랙에서 쓰기

- **앱처럼 설치:** HTTPS 주소로 열고 안드로이드(Chrome)는 메뉴 → **홈 화면에 추가**, 아이폰(Safari)은 공유 → **홈 화면에 추가**.
- **신호가 약해도 돼요.** 한 번 연 기기는 인터넷이 끊겨도 마지막으로 본 내용으로 열려요. 끊긴 동안 바꾼 점검 체크·기록·부품은 기기에 저장해 두고(오른쪽 위 "오프라인 · 저장 대기 N"), 연결되면 자동으로 올려요.
  - 그 사이 권한이 바뀌었거나 지워진 항목은 올라가지 않고 알려 줘요.
  - 첨부 파일과 사비 내역서는 연결된 뒤에 올려요.
- **트랙 가기 전에 한 번 열어 두세요.** 열어 본 적 없는 기기는 오프라인에서 열리지 않아요.
- **같은 기기를 여러 사람이 쓰면 꼭 로그아웃하세요.** 로그아웃하면 기기에 저장한 데이터도 지워져요. 단, 저장 대기 중인 내용이 있으면 먼저 올라갔는지 확인하세요.

## 11. 공방 TV 화면

오른쪽 위 **TV**를 누르면 작업실 모니터용 읽기 전용 화면이 돼요. 큰 D-day, 제작 진행률·질량·예산, 부서별 완료 막대, 마감 지남·임박 부품, 미해결 테스트 이슈, 다가오는 일정, 그날 세션의 점검 진행을 보여 주고, 바뀐 내용은 바로 반영돼요.

- **전체 화면** 버튼(안 되면 F11)으로 꽉 채워요.
- 그 기기에서 선택이 기억돼서 모니터 PC를 다시 켜도 TV 화면으로 열려요. 주소 끝에 `?view=tv`를 붙여 북마크해도 돼요.
- Esc나 **일반 화면으로**로 돌아가요.

## 12. 임원진 · 총무가 하는 일

| 누구 | 추가로 할 수 있는 일 |
|---|---|
| 임원진 (팀장 · 부팀장 · 파트장) | **⚙ 차량 설정**(차량 이름, 대회 날짜, 목표 질량, 부품 예산), **점검 항목 편집**, **일정 추가·수정**, 부품 잠금(파트장은 자기 부서만) |
| 총무 (부팀장) | 사비 정산 처리: 상태 변경, 지급일·지급 금액·메모, 수정본 교체, 삭제·복구, 대리 등록, 전체 계좌번호 보기, **정산 내역 CSV** |
| 개발자 | 모든 권한, 관리 창(`/admin`): 가입 승인, 직책·부서 변경, 비밀번호 초기화, 백업 |

- **대회 날짜**를 차량 설정에 넣어야 머리글 D-day가 떠요. **목표 질량·예산**을 넣으면 부품 현황에서 대비 비율이 보여요.
- **점검 항목 편집**은 테스트 세션 화면에서 해요. 한 줄에 한 항목씩 적고, 바꾼 항목은 앞으로 만드는 세션부터 적용돼요. "지금 보고 있는 세션에도 적용"을 체크하면 현재 세션에도 반영돼요(이미 체크한 항목은 유지).
- **일정** 탭에는 "자주 쓰는 일정"(설계 보고서, 비용 보고서(BOM), ESF, 차량 검사, 대회 본선) 버튼이 있어 빠르게 넣을 수 있어요.
- **총무 처리**는 내역서를 열면 아래에 "총무 처리" 칸이 있어요. 메모는 신청자에게도 보여요. 처리 기록은 관리 창 감사 로그에도 남아요.
- 팀장·부팀장은 한 명, 파트장은 부서마다 한 명이에요. 직책은 개발자가 관리 창에서 정해요.

## 13. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 부서를 잘못 골랐어요 / 이름을 바꾸고 싶어요 | 개발자에게 요청하세요. 관리 창에서 바꾸면 열어 둔 화면에도 바로 반영돼요 |
| 부품을 고칠 수 없어요 | 🔒 잠긴 부품이에요. 그 부서 파트장이나 팀장·부팀장에게 요청하세요 |
| 차량 설정·일정 추가 버튼이 안 보여요 | 임원진만 할 수 있어요 |
| 사비 내역서가 "양식 불일치"로 나와요 | 결과 화면에 나온 칸을 고쳐서 다시 올리세요. 양식 파일 자체가 이상하면 총무에게 원본 양식을 받아요 |
| 제출한 내역서에 실수가 있어요 | 직접 고칠 수 없어요. 총무에게 수정본 교체를 부탁하거나 새로 제출하세요 |
| "오프라인 · 저장 대기"가 계속 떠요 | 인터넷 연결을 확인하세요. 연결되면 자동으로 올라가요. 그 전에 로그아웃하지 마세요 |
| 알림이 안 와요 | 부품의 담당자가 내 계정으로 지정돼 있는지 확인하세요. 마감·일정 알림은 아침 8시 이후에 와요 |
| 누가 바꿨는지 알고 싶어요 | 변경 이력 탭에서 종류별로 볼 수 있어요 |

### claude.ai에서 쓸 때 다른 점

지금처럼 claude.ai Artifact로 쓸 때는 가입·로그인 없이 claude.ai 계정으로 들어가요.

- 오른쪽 위 **내 이름** 칸에 이름을 적고, 오늘 탭에서 **내 부서**를 직접 골라요.
- 알림, 오프라인 사용, 앱 설치, 관리 창은 자체 서버에서만 돼요.
- 총무는 소유자가 **사비 정산 → 권한 관리**에서 지정해요. 목록에는 페이지를 한 번 이상 연 사람만 나와요.
- "보기 전용으로 열려 있어요"가 뜨면 소유자에게 편집자로 초대해 달라고 요청하세요.
