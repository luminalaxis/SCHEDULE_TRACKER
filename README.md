# FSK 피트보드

FSK(Formula Student Korea) 차량 제작동아리용 팀 현황판입니다. 부품 제작 진행, 주행 테스트, 대회 일정, 사비 정산을 한 페이지에서 30명 안팎의 팀원이 함께 씁니다.

같은 `index.html`이 두 곳에서 돌아갑니다.

- **자체 서버 (라즈베리파이 등, 최종 운영용):** `server/` 의 Node.js 서버가 로그인, 데이터베이스(SQLite), 실시간 동기화, 첨부 파일, 권한을 맡고, 개발자 전용 관리 창(`/admin`)을 제공해요. 설치는 [deploy/RASPBERRY_PI.md](deploy/RASPBERRY_PI.md).
- **claude.ai Artifact (지금 쓰는 곳):** 데이터는 Artifact의 공유 데이터베이스와 파일 저장소에 있어요.

이 저장소에는 코드와 설정만 있고 팀 데이터는 없습니다.

## 빠른 시작 (자체 서버)

```bash
# Node.js 22.13 이상, 설치할 패키지 없음
npm start                    # http://127.0.0.1:8080 , 데이터는 ./data
npm test                     # 서버 API 테스트
```

처음 가입하는 사람이 개발자 계정이 되고, 이후 가입은 개발자가 승인해요. 환경 변수: `PORT`(8080), `HOST`(127.0.0.1), `DATA_DIR`(./data), `TRUST_PROXY`(터널 뒤에서 1), `COOKIE_SECURE`.

## 개발자 관리 창 (`/admin`)

| 탭 | 내용 |
|---|---|
| 개요 | 서버 가동 시간, 접속 중인 사람, 사용자 수, 마지막 백업, DB·첨부 파일·디스크·메모리 사용량, 컬렉션별 문서 수, 경고(승인 대기, 백업 오래됨, 디스크 부족, HTTPS 아님) |
| 사용자 | 조직 현황(팀장·부팀장·부서별 파트장), 가입 승인·거절, 직책·개발자 권한·상태·부서 변경, 비밀번호 초기화(임시 비밀번호), 강제 로그아웃, 계정 직접 만들기·삭제 |
| 데이터 | 컬렉션·문서 탐색과 검색, JSON 직접 수정·생성·삭제 (버전 충돌 확인, 열린 화면에 바로 반영) |
| 백업 · 복원 | 지금 백업, 백업 내려받기·복원·삭제, JSON 가져오기(합치기/전체 교체). 복원·가져오기 직전 상태는 자동 보관 |
| 첨부 파일 | 전체 파일 목록, 어디에서도 쓰지 않는 파일 찾기·정리 |
| 감사 로그 | 서버가 남기는 기록: 로그인·로그인 실패·가입·권한 변경·데이터 직접 수정·백업·파일 삭제 (IP 포함) |
| 설정 | 가입 방식(승인제·초대 코드·닫힘), 초대 코드 재발급, 자동 백업 시각·보관 개수, 팀원 사비 내역서 제출 허용, 내 비밀번호 변경 |

조직과 권한:

| 구분 | 누구 | 할 수 있는 일 |
|---|---|---|
| 개발자 | 개발자 권한을 받은 사람 | 모든 데이터 쓰기, 관리 창, 사비 정산 완전 삭제 |
| 임원진 | 팀장 · 부팀장 · 파트장(부서마다) | 팀원 권한 + 차량 설정, 출주 전 점검 항목, 일정 관리 |
| 총무 | 부팀장이 겸직 | 임원진 권한 + 사비 정산 지급 처리·수정본 교체·삭제·대리 등록 |
| 팀원 | 직책 없는 사람 | 부품·테스트 세션·부서 기록 작성, 사비 내역서 제출, 첨부 파일 올리기 |

- 팀장·부팀장은 한 명, 파트장은 부서마다 한 명이에요. 새로 지정하면 이전 사람은 자동으로 팀원이 돼요.
- 개발자도 직책을 겸할 수 있어요 (예: 개발자이면서 부팀장이면 총무 업무도 함).
- 마지막 개발자 계정은 개발자 권한을 빼거나 비활성화할 수 없어요. 웹 관리 창에 들어갈 수 없을 때는 `npm run admin -- reset-password <아이디>` 같은 명령으로 복구해요.

## 사비 정산

### 양식 자동 검사

동아리 양식 `개인사비사용내역서_이름_날짜.xlsx`를 브라우저에서 바로 읽어 검사합니다(JSZip, 엑셀·한셀 저장 파일 모두 지원).

- `내역서`·`영수증` 시트, 2행 머리글(B2:K2)
- 각 항목: 필수 칸, 팀명·구분이 양식의 숨김 목록 값인지, 날짜, 단가·수량 숫자, 합계 = 단가 × 수량
- 총 합계(K13), 계좌번호(H13) 자릿수·은행명
- 영수증 사진 유무와 구매 건수 대비 장수
- 배송비 구분, 구매처 링크·주소, 파일명 규칙, 같은 파일 중복 제출

결과는 `양식 통과` / `확인 필요` / `양식 불일치` 세 단계이며, 팀원은 양식 불일치 파일을 제출할 수 없습니다.

### 지급 상태

`검토 대기` → `보완 요청` / `승인 · 지급 대기` → `지급 완료` / `반려`

### 권한

| | 팀원 | 총무 | 개발자(소유자) |
|---|---|---|---|
| 내역서 제출 | ✅ (설정으로 끌 수 있음) | ✅ (대리 등록 포함) | ✅ |
| 지급 상태 변경, 수정본 교체 | ❌ | ✅ | ✅ |
| 전체 계좌번호 보기, 원본 내려받기 | 본인 것만 내려받기 | ✅ | ✅ |
| 삭제(목록에서 숨김)·복구 | ❌ | ✅ | ✅ |
| 완전 삭제(데이터·파일) | ❌ | ❌ | ✅ |
| 총무 지정 | ❌ | ❌ | ✅ |

권한은 서버의 데이터베이스 규칙(`artifact.config.json`)으로 보호됩니다.

- 각 사람은 자기 영역(`expenses/<id>`, `reviews/<id>`, `people/<id>`)에만 쓸 수 있습니다.
- `config/roles`(총무 목록)는 소유자만 쓸 수 있습니다.
- 지급 상태는 `reviews/<id>`에 기록되며, 페이지는 총무 목록에 있는 사람(과 소유자)의 기록만 인정합니다.

알려진 한계:

- 제출자는 자기 영역에 있는 제출 내용을 기술적으로 바꿀 수 있습니다. 총무 검토 뒤 내용이 바뀌면 "검토 후 변경됨"으로 표시됩니다.
- 화면 이름은 각자 입력한 이름입니다. 권한은 이름이 아니라 claude.ai 계정 기준입니다.
- 원본 xlsx는 지원 형식 제한 때문에 base64 텍스트로 저장됩니다. 페이지를 열 수 있는 사람에게서 완전히 숨겨지지는 않습니다.

| `sessions/*` | 테스트 세션 (생성 시점의 점검 항목 사본 포함) |

| `checks/<세션>--<항목>` | 점검 체크 |

## 구조

```
index.html                  페이지 본문 (Artifact와 자체 서버가 함께 씀)
artifact.config.json        권한 규칙 (Artifact 게시 설정이자 서버의 권한 규칙)
server/server.js            HTTP 서버: 로그인, db API, 실시간(SSE), 첨부 파일, 관리 API, 자동 백업
server/store.js             SQLite 문서 저장소, 경로 규칙, 권한 규칙 엔진, 쿼리
server/auth.js              계정, scrypt 비밀번호, 세션 쿠키
server/cli.js               명령줄 관리 도구 (비밀번호 초기화, 계정 생성, 백업·복원)
server/public/fsk-runtime.js  페이지의 window.claude.use(...) 를 이 서버로 연결하는 런타임
server/public/login.html    로그인·가입·임시 비밀번호 변경
server/public/admin.html    개발자 관리 창
deploy/                     라즈베리파이 설치 안내, systemd 서비스 파일
test/server.test.js         서버 API 테스트
```

`index.html` 은 `<!doctype>`·`<head>` 없이 본문만 있어요. claude.ai는 게시할 때, 자체 서버는 보낼 때 문서 틀로 감싸요. 자체 서버는 이때 로그인한 계정 정보와 `fsk-runtime.js` 를 함께 넣어서, 페이지 코드를 고치지 않고도 같은 데이터 API·권한·실시간 동기화가 동작해요.

## 보안 (자체 서버)

- 비밀번호는 scrypt로 해시, 세션은 HttpOnly·SameSite 쿠키 (30일), HTTPS 뒤에서는 Secure
- 쓰기 요청은 같은 출처 + 전용 헤더가 있어야 처리 (CSRF 방지)
- 로그인 실패 15분 10회 제한, 실패도 감사 로그에 기록
- 페이지에 CSP 적용, 첨부 파일은 로그인한 사람에게만, 샌드박스 헤더로 제공
- 권한은 `artifact.config.json` 규칙 + 계정 역할로 서버에서 검사
